# JAHIS QR 薬品コード空欄時の完全性判定修正（2026-08-06）

## 現象

調剤モードで、単一のJAHIS QRコードをカメラで正常に読み取れているにもかかわらず、解析時に「RP1 の薬剤レコードが不完全です」と表示され、調剤監査へ進めない事象が発生した。

## 実機ログで確認したこと

- QRコードは1個の断片として認識された。
- 構造化追加（Structured Append）の順序情報は付与されていなかったが、単独QRとして処理可能な状態だった。
- 組み立て時に `MISSING_DRUG_RECORD` と判定された。

QR本文および患者情報はログへ保存・記録していない。

## 原因

`JahisCompletenessChecker` が、薬品名・数量・単位に加えて、薬品コード種別と薬品コードも必須項目として扱っていた。

一方、`JahisQrParser` は薬品名・数量・単位があれば薬剤レコードを処理できるため、判定と解析の条件が不一致だった。薬品コード欄が空欄のJAHIS QRは、この不一致により解析前に拒否されていた。

## 対応

- TC01 / TC07: 薬品名・数量・単位があり、規定の列数を満たす薬剤レコードを有効とする。
- TC02以降: 薬品名・数量・単位があり、規定の列数を満たす薬剤レコードを有効とする。
- 薬品名、数量または単位が欠けるレコードは、従来どおり不完全として扱う。

## 検証

- `JahisCompletenessCheckerTest` に、TC01およびTC02の薬品コード・種別が空欄のケースを追加した。
- 実機で、従来エラーとなっていたQRが調剤モードで読み込めることを確認した。
